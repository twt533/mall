该项⽬为电商商城后台管理系统，涵盖⽤户管理、商品管理、订单管理、⽀付管理、库存管理、营销活动、数据统计等核⼼模块，⽀撑前端商城⽤户下单、⽀付、售后等全流程业务。
使⽤ Spring Boot、Spring Cloud、MySQL、Redis、Sentinel、Maven、Docker 实现。订单创建、⽀付回调、订单超时取消、库存扣减、库存回滚等功能逻辑，保证订单与库存数据⼀致性。
基于 Redis实现商品热点数据缓存、⽤户登录令牌存储、秒杀接⼝限流，解决秒杀场景下⾼并发、超卖问题，⽀撑万⼈秒杀活动。通过 RabbitMQ 实现订单超时取消、物流信息异步通知、库存异步更新，实现业务解耦，提升系统响应效率，避免同步阻塞导致的接⼝超时。
使⽤ Elasticsearch 构建商品检索功能，实现商品关键词模糊查询、分类筛选、价格排序，优化⽤户检索体验，检索响应速度提升 60%。
整合 Sentinel 实现服务熔断、限流、降级，针对核⼼接⼝设置流量阈值，防⽌服务雪崩，保障⾼并发场景下系统稳定性。
优化订单数据库架构，采⽤分表策略拆分历史订单数据，解决单表数据量过⼤导致的查询缓慢问题，提升⼤数据量查询性能。
